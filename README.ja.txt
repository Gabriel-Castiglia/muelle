Muelle
======

Gabriel Castiglia · 2026 年 11 月 26 日 · バージョン 2.5.1 · GPL-2.0-only

English (README.txt) · Español (README.es.txt) · 日本語

PDF マニュアル: docs/Muelle-manual-ja.pdf

  Windows 10/11 の x64（64 ビットの Intel または AMD）専用です。 ARM
  プロセッサ用のビルドはありません。

Muelle は Windows 10 と 11 のためのアプリケーションドックで、C#、.NET 10、WPF
で書かれています。macOS 風にポインターの下のアイコンが拡大されるフローティングドックにも、Ubuntu
風に画面の端から端まで届く固定パネルにもできます。画面の言語は英語、スペイン語、日本語で、セットアップで選んだ言語で起動し（インストールせずに実行した場合は英語）、いつでも変更できます。外観はライト、ダーク、または
Windows に合わせることができ、12 色から色を選べます。複数のショートカットを 1
つのアイコンにまとめる「スタック」、画面ごとのアイコン、新しいバージョンの自動インストールにも対応しています。「Muelle」はスペイン語で船が係留される「埠頭」を意味します。

動作環境
----

- Windows 11、または Windows 10 バージョン 1803 以降。x64 プロセッサ（64 ビットの Intel または
  AMD）。

ほかにインストールするものはありません。Muelle は自分の .NET
ランタイムを内蔵しており、セットアップ画面は Windows に最初から入っている .NET Framework
で動きます。

インストール
------

最新リリース <https://github.com/Gabriel-Castiglia/muelle/releases/latest>からファイルをダウンロードします。入手方法は
3 つあり、どれも scripts\build.ps1 が dist フォルダーに作ります。

  ファイル           内容
  ------------------ -------------------------------------------------------------------------------------------------------------
  muelle-setup.exe   セットアッププログラム（英語、スペイン語、日本語）。通常はこれでインストールします。
  muelle.msi         同じインストールの Windows インストーラー パッケージ。サイレントインストール用: msiexec /i muelle.msi /qn。
  Muelle.exe         プログラム単体。インストールせずに任意のフォルダーから実行できます。

各リリースの SHA256SUMS.txt で、ダウンロードしたファイルを先に確認できます（PowerShell で
Get-FileHash muelle-setup.exe）。

セットアップを起動すると、右上に言語メニュー（英語、スペイン語、日本語の順）のある画面が開き、選ぶとすべてのページの言語がすぐに切り替わります。Muelle
はすべてのユーザー向けに C:\Program Files\Muelle
にインストールされるため管理者権限が必要です（インストール開始時に Windows
が確認します）。スタートメニューにも追加されます。セットアップで選んだ言語が、ドックを初めて起動したときの言語になります。

新しい muelle-setup.exe を実行すると、インストール済みの Muelle
が更新され、各ユーザーの設定はそのまま残ります。Muelle
が実行中なら、セットアップがファイルを置き換える前に終了させ、完了後に再び起動します。新しいバージョンの上に古いバージョンをインストールすることはできません。インストール済みの
Muelle は自分で更新することもできます。新しいバージョン (#新しいバージョン)を参照してください。

画面を出さずにインストールするには: muelle-setup.exe /quiet（管理者権限の確認は表示されます）。

Windows と一緒に Muelle を起動するには、設定 → 動作 →「Windows の起動時に Muelle
を開始する」をオンにします。Muelle を起動するタスク スケジューラのタスク（\Muelle (inicio de sesion)
または
\Muelle）を自分で作ってある場合は、このチェックボックスはそのタスクに従います。オンにするとタスクが有効に、オフにすると無効になり、二重に起動しないようレジストリの「Run」キーは使われません。

アンインストール
--------

Windows の設定 → アプリ → インストールされているアプリで Muelle
を探し、「アンインストール」を選びます。言語メニュー付きの同じセットアップ画面が、インストール時に選んだ言語で開きます。Muelle
が実行中なら終了させ、プログラムとスタートメニューのショートカットを削除し、アンインストールしたユーザーの「Windows
と一緒に起動」の登録も削除します。

各ユーザーの設定（%APPDATA%\Muelle）は残るので、あとで再インストールしたときに引き継がれます。設定も消すには、そのフォルダーを削除してください。

画面を出さずにアンインストールするには: muelle-setup.exe /uninstall /quiet。

ドックの使い方
-------

- アイコンをクリックするとアプリが開きます。すでに開いていれば、そのウィンドウが前面に出ます。ウィンドウが複数あるときは、クリックするたびに次のウィンドウが出ます。すでに前面にある唯一のウィンドウをクリックすると最小化されます。Shift +
  クリックまたは中クリックで新しいウィンドウを開きます。
- アプリの起動中はアイコンが弾み、開いているアプリにはアイコンの下に点が付きます。
- アイコンはアプリに追従します。アプリが更新されたとき（ストアアプリも）、アプリが自分のアイコンの色を変えたとき（Vigía
  がテーマの色で変えるように）、ショートカットや選んだアイコンファイルが変わったときは、再起動しなくても
  15
  秒以内に新しいアイコンになります。プログラムの場合、プログラム自身のショートカットが指すアイコンファイルがプログラムのフォルダーにあれば、ドックはそれを使います。1
  つのショートカットに別の場所から手で選んだアイコンはそのまま残ります。
- ドックにない開いているアプリは末尾に表示され、閉じると消えます。メニューの「ドックに固定」、またはほかのアイコンの間へのドラッグで残せます。
- アプリは、ショートカットや .exe
  をドックにドロップするか、ドックのメニューの「アプリケーションを追加…」、または設定から追加します。ストアアプリ（Teams、ターミナルなど）やコントロールパネルのようなシェルオブジェクトも追加できます。
- アイコンはドックに沿ってドラッグすると並べ替えられ、ドックの外へドラッグすると削除されます。「ドックをロック」にするとどちらもできなくなり、メニューからの固定、外す操作、名前の変更もできなくなるので、うっかり変えてしまうのを防げます。
- スタックは複数のショートカットを入れた 1
  つのアイコンで、クリックすると横に広がります。スタック (#スタック)を参照してください。
- アイコンが画面に収まらないときは、その画面のアイコンだけが小さくなります。
- 全画面のアプリ（動画、ゲーム）が前面にある間、ドックは完全に隠れ、ポインターを画面の端に動かしても出てきません。アプリが全画面をやめると戻ります。

アイコンを右クリックすると短いメニューが出ます。新しいウィンドウを開く（アプリが閉じているときは「開く」）、名前の変更…、ドックに固定またはドックから外す、その他（管理者として実行、ファイルの場所を開く、スタックへ移動）、続いてドックをロック、設定…、Muelle
を終了。「タスクの終了」はアプリの実行中だけ、最後に離して表示されます。ドックの何もないところを右クリックすると、アプリケーションを追加…、新しいスタック…、ドックをロック、設定…、Muelle
を終了が出ます。それ以外（スタイル、言語、外観、更新、バージョン情報）はすべて設定にあります。名前を空にして変更すると、プログラム本来の名前に戻ります。

スタック
----

スタックは Mac のドックのスタックのように、複数のショートカットを 1
つのアイコンにまとめます。クリックするとショートカットがそれぞれのアイコン付きで横に広がり、1
つをクリックするとそれが開きます（すでに開いていればそのウィンドウが前面に出ます）。一覧の最後の「スタックを編集…」でスタックエディターが開きます。

- ドックのメニュー、または設定 → ドックのアプリケーションの「新しいスタック…」で作成します。
- エディターでは、スタックの名前、アイコン（専用のもの:「アイコンを選択…」で
  .ico、プログラム、画像のどれか。または「自動アイコン」: 最初の 4
  つのショートカットを格子状に並べたもの）、ショートカット（追加…、削除、上へ、下へ）を設定します。「保存」するまでドックは変わりません。編集中にスタックがドックからなくなった場合（削除された、または「画面ごとに別のアイコン」を切り替えた）、「保存」はそう伝えて何も変えません。
- アイコンのメニューの「スタックへ移動」で、そのアイコンをスタックの末尾に入れます。
- スタックはほかのアイコンと同じように移動や削除ができます。スタックに入っているアプリは、開いていてもドックの末尾にもう一度表示されることはありません。

画面ごとのアイコン
---------

すべての画面にドックを出すと、既定ではどのドックにも同じアイコンが並びます。設定 → 位置
→「画面ごとに別のアイコン」にすると、画面ごとに別の一覧になります。初めて見る画面は共通のアイコンのコピーから始まり、それ以降はその画面のドック、または設定
→
ドックのアプリケーション（画面を選ぶ「アイコンの対象:」一覧が加わります）で、追加、削除、並べ替えができます。

Muelle は画面を、Windows
が物理モニターとその接続端子に付ける名前で見分けるので、再起動しても画面の順番が変わってもアイコンは保たれます。Windows
がその名前を出さない場合は、表示名と解像度で見分けます。画面を外してもそのアイコンは設定に残り、もう一度つなぐと戻ります。オプションをオフにすると共通のアイコンに戻り、画面ごとのアイコンは次回のために保存されます。

設定
--

ドックを右クリック → 設定…。変更はすぐに反映されます。Muelle.exe --settings
で起動すると、設定画面が開いた状態で Muelle が始まります（ショートカット用に便利です）。

  グループ                   オプション
  -------------------------- ------------------------------------------------------------------------------------------------------------------------------------------------------------------
  スタイル                   フローティングドック（Mac 風）または固定パネル（Ubuntu 風）、パネルの不透明度。
  位置                       画面の端、メイン画面・すべての画面（それぞれに 1 つ）・特定の画面、画面ごとのアイコン。
  動作                       画面の帯を確保する、自動的に隠す、固定していない開いているアプリを表示する、ドックをロックする、Windows と一緒に起動する、新しいバージョンを確認する。
  外観                       Windows に合わせる、ライト、ダーク。12 色から 1 色。
  アイコン                   サイズ（24〜96 px）、ポインターの下での拡大（最大 2 倍）、フローティングドックの背景。
  言語                       英語、スペイン語、日本語。
  ドックのアプリケーション   固定したアプリとスタックの一覧。追加、新しいスタック、スタックを編集（またはダブルクリック）、削除、上へ、下へ。画面ごとのアイコンのときは、一覧を表示する画面。

外観
--

Muelle はライト、ダーク、または Windows のアプリの設定（設定 → 個人用設定 →
色）に合わせることができ、Windows
の設定が変わるとすぐに切り替わります。ドックは明るいすりガラスか暗いガラスになり、設定、バージョン情報、更新の各ウィンドウもタイトルバーを含めてそれに従います。外観は設定
→ 外観で選びます。

色は 12 色あります。選んだ色は、開いているアプリの下の点、スイッチ、スライダー、選択した項目、そして
Muelle
のウィンドウのアイコン（その色のタイルの上を船が進みます）に使われます。スタートメニューのアイコンは青のままです。Muelle
はすべてのユーザー向けにインストールされ、そのショートカットは全員のものだからです。

以前のバージョンの設定ファイルはそれまでのダークのドックのままで、新しくインストールした場合は
Windows に合わせます。

新しいバージョン
--------

Muelle は 1 日に 1 回、GitHub に最新リリースを問い合わせます。バージョン情報（設定
→「バージョン情報…」）の「更新を確認」で、いつでも確認できます。新しいバージョンがあると、小さなウィンドウが「今すぐ更新」「新機能を見る」（リリースページ）「後で」のどれにするかを尋ねます。「今すぐ更新」を選ぶと、あとはすべて自動で進みます。

1.  そのリリースの SHA256SUMS.txt には作者の署名（release.sig。Muelle に組み込まれた 2
    つの公開鍵で確認します）が付いていなければなりません。有効な署名のないリリースは拒否され、そのページから手動でダウンロードするしかありません。続いてセットアップ
    muelle-setup.exe が %TEMP%\MuelleUpdate にダウンロードされ、その SHA256SUMS.txt
    と照合されます。一致しないファイルは削除され、実行されません。
2.  Muelle は自分の起動方法を記録して終了します。
3.  セットアップが、インストール時に選んだ言語で、画面を出さずにインストールします。ほかのインストールと同じく、Windows
    が管理者権限を確認します。Muelle
    の終了を待ち、インストールフォルダーから実行中のほかのコピーも終了させます。
4.  Muelle が同じ引数でもう一度開き、更新されたことを伝えます。

何かが失敗した場合は何もインストールされません。Muelle
はそのまま動き続けるか再び開き、何が起きたかを伝えます（たとえば管理者権限が拒否されたとき）。インストールせずに実行している
Muelle.exe は自分を置き換えられないので、その場合はリリースページだけを案内します。

問い合わせで送るのは、プログラム名とバージョンだけです。毎日の確認は設定 → 動作でオフにできます。

言語
--

画面は英語、スペイン語、日本語です。言語は設定で変更でき（どの言語からでも見つけられるよう「Language
/ Idioma / 言語」と 3 か国語で表示）、変更は記憶されます。セットアップ画面は、Muelle
が別の言語ですでにインストールされていない限り英語で始まります。Muelle
が初回起動時に追加するアプリの名前（エクスプローラー、メモ帳、電卓など）は画面の言語に従います。

ファイル
----

  内容                             場所
  -------------------------------- --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  インストールされたプログラム     C:\Program Files\Muelle。LICENSE.txt、README.txt、README.es.txt、README.ja.txt も一緒です
  設定                             %APPDATA%\Muelle\config.json（削除すると最初からやり直せます）。最後に保存する前の版は config.previous.json
  読めなかった設定                 このバージョンが読めないアイコンや設定はそれだけが外され、一覧全体が消えることはありません。外されたものは config.dropped-<日付>.json に、元のファイル全体は config.partial-<日付>.json に保存されます
  エラーログ（何か失敗したとき）   %APPDATA%\Muelle\muelle.log。512 KB 以下に保たれます（前の部分は muelle.old.log）
  インストール中の更新             %TEMP%\MuelleUpdate（セットアップと Muelle の起動方法）。更新のインストールから 1 分後に削除されます

既知の制限
-----

- Muelle が画面の帯を確保すると、Windows
  はその下にあったデスクトップアイコンを並べ直し、別のモニターに移すことがあります。これはアプリケーションバー全般に対する
  Windows
  の動作です。困る場合は「画面の帯を確保する」をオフにしてください。その場合、最大化したウィンドウはドックの下に入ります。

ソースからのビルド
---------

.NET 10 SDK <https://dotnet.microsoft.com/download> をインストールした状態で:

    dotnet build src\Muelle\Muelle.csproj -c Release
    powershell -ExecutionPolicy Bypass -File scripts\build.ps1

1 つ目のコマンドはプログラムをビルドします。2 つ目は dist にすべてを作ります。単体の
Muelle.exe、muelle.msi、muelle-setup.exe を作り、それぞれの SHA-256 を表示します。WiX Toolset 5 は
NuGet パッケージとして自動で復元されます。リリースには muelle-setup.exe、SHA256SUMS.txt、release.sig
がこの名前で必要です。更新機能がこれらを探すためです。

Muelle.exe --self-test <ログ>
は、設定ファイル、スタック、画面ごとのアイコン、アプリに追従するアイコン、全画面アプリの検出、更新機能（バージョンの比較、ハッシュ、署名、セットアップのコマンドライン）を確認し、確認ごとに
1 行をログに書きます。終了コードは失敗の数です。%TEMP%
の使い捨ての設定フォルダーで動いて最後に削除し、ウィンドウは表示せず、実行中の Muelle
には触れません。--online
を付けると、最新リリースのセットアップもダウンロードして（実行はせずに）SHA256SUMS.txt
と署名で確認します。バージョンは src\Muelle\Muelle.csproj の 1
か所だけで設定され、インストーラーとバージョン情報画面はそこから読みます。

scripts\screenshots.ps1 はサンプルのアプリで docs\images
の画像を作ります（デスクトップのセッションから実行します。SSH
経由ではドックの画像が空になります）。scripts/manual.sh（pandoc と Google Chrome が必要。macOS
または Windows の Git Bash で動きます）は、README から PDF マニュアルと
README.txt、README.es.txt、README.ja.txt を作ります。scripts/make_icon.py は assets/
の版画からアイコンを 12 色で描きます（Python 3 と numpy、opencv-python、Pillow）。

  フォルダー          内容
  ------------------- ---------------------------------------------------------------------------
  src/Muelle          プログラム。
  installer/Msi       MSI パッケージ（WiX）。
  installer/SetupUI   セットアップ画面。英語、スペイン語、日本語（.NET Framework 4.7.2、WPF）。
  installer/Setup     セットアップ画面と MSI を入れたセットアッププログラム（WiX バンドル）。
  scripts             ビルド、画像、アイコン、マニュアル。
  assets              アイコンの元になった版画。
  docs                PDF マニュアル、画像、マニュアルのスタイルシート。
